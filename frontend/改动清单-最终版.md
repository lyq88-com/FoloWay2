## 一、习惯打卡模块 · 断卡/补卡机制

### 1. `common/mock.js`
- 新增工具函数 `_todayStr(offset)`、`_daysSince(dateStr)`
- 新增 `applyStreakBreak(habit)` 断卡判定算法：
  - 今日已打卡 → 清除补卡资格
  - 从未打卡的新习惯（`streak<=0` 且无 `broken_streak`）→ 不标记断卡
  - 距上次打卡超过 0 天 → `broken=true`、`broken_streak` 记录原连续天数、`streak=0`
  - 漏卡恰好 1 天（昨天漏卡）→ `can_makeup=true`（1 天宽限期，跨天自动失效）
- mockHabits 数据补充 `last_checkin_date` 字段（今日/昨日/3 天前三档，覆盖不同断卡状态）
- 新增 `mockMakeupCheckin(habitId)`：恢复 `streak = broken_streak + 1`，清除断卡标记
- `mockGetTodayHabits` / `mockGetAllHabits` 返回前统一过 `applyStreakBreak`
- 导出表新增 `makeupCheckin`

### 2. `api/habit.js`
- 新增 `makeupCheckin(habitId)` 接口（mock / 真实接口双通道）

### 3. `components/habit-card/habit-card.vue`
- 新增"断卡"标签（显示原连续天数）
- 新增"补卡"胶囊按钮，`@click.stop` 触发 `$emit('makeup', habit)`

### 4. `pages/habit/habit.vue`
- 新增 `handleMakeup(habit)`：调 API → 更新习惯状态 → `addAffection +1` → toast → AI 鼓励语
- 兼容 mock 包装返回与裸对象两种结构（`res.data || res`）
- 防重复提交（`makeupSubmitting` 标志）
